# Post reply — posting refused

## Trigger

The selected destination reaches the posting refusal branch.

## Outcome

The posting failure is displayed without storing the proposed contribution.

## Edge cases

- A locked literal-reply destination takes its own lock refusal; pending-topic/source restrictions and quote refusal use the separately selected branches.
